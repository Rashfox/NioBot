Panduan Nio

Pasang Nio di komputer atau server milikmu, sambungkan WhatsApp, lalu gunakan perintah lewat chat. Panduan ini untuk menjalankan bot dari source code.

Perlu diketahui
Nio adalah bot WhatsApp yang dijalankan di perangkat/server kamu, bukan aplikasi web yang bisa dijalankan dari halaman GitHub Pages. Demo di beranda hanya simulasi tampilan dan perintah.

1. Persiapan

Pastikan perangkat sudah memiliki:

  • Node.js 18 atau lebih baru (disarankan versi LTS).
  • FFmpeg terpasang dan tersedia di PATH untuk fitur stiker/video dan audio.
  • Akun WhatsApp untuk menautkan perangkat bot.
  • API key Gemini jika ingin menggunakan Google Gemini. Provider lain dapat dikonfigurasi setelah bot aktif.

2. Instalasi

Clone repository, lalu pasang dependensi:

git clone https://github.com/Rashfox/NioBot.git
cd NioBot
npm install

Salin template konfigurasi menjadi .env (di PowerShell gunakan Copy-Item .env.example .env), lalu isi konfigurasi dasarnya:

cp .env.example .env
GEMINI_API_KEY=isi_api_key_kamu
OWNER_NAME=NamaKamu
OWNER_NUMBER=628xxxxxxxxxx
OWNER_LID=
BOT_PREFIX=.

OWNER_NUMBER gunakan kode negara tanpa tanda +. API key bersifat rahasia—jangan bagikan atau commit file .env.

Jalankan bot dengan:

npm start

3. Hubungkan WhatsApp

Saat pertama dijalankan, pilih salah satu metode login dari terminal:

  1. Scan QR: buka WhatsApp → Perangkat tertaut → tautkan perangkat, lalu scan QR yang muncul di terminal.
  2. Pairing code: pilih opsi pairing, masukkan nomor dengan kode negara, lalu masukkan kode yang ditampilkan lewat menu perangkat tertaut WhatsApp.

Sesi tersimpan pada folder auth_session. Jangan bagikan folder ini; siapa pun yang memilikinya mungkin dapat mengakses sesi bot.

4. Perintah populer

Prefix bawaan adalah titik (.). Kirim perintah ke chat pribadi atau grup yang diikuti bot.

PerintahKegunaan
.menuMelihat menu perintah bot.
.ai <pertanyaan>Mengirim pertanyaan ke provider AI aktif.
.nio <pesan>Ngobrol dengan persona Nio.
.chatnioMemulai chat tanpa prefix; sesi berakhir setelah 10 menit tidak aktif.
.stopchatMengakhiri sesi chat interaktif.
.tts <teks>Mengubah teks menjadi pesan suara.
.ttsanime <teks>Membuat pesan suara dengan pilihan suara anime.
.stikerBalas/kirim gambar atau video pendek dengan caption perintah untuk membuat stiker.
.qc <teks>Membuat stiker quote chat.
.smeme teks atas | teks bawahMembuat meme dari teks.
.sholat <kota>Melihat jadwal sholat untuk kota yang dicari.
.menugifMelihat kategori GIF/stiker animasi.
.pingMemeriksa respons bot.

Beberapa perintah tambahan tersedia di .menu. Pengelolaan provider dan sejumlah perintah profil hanya dapat digunakan oleh owner.

5. Atur provider AI

Gemini, OpenRouter, dan endpoint lokal OpenAI-compatible (misalnya Ollama) dapat dikelola melalui chat sebagai owner:

  • .setai — lihat provider yang tersedia dan statusnya.
  • .setai <provider> — pilih provider, misalnya .setai gemini.
  • .setaimodel [provider] <model> — pilih model untuk provider.
  • .setaikey [provider] <api_key> — simpan API key provider.
  • .setaiurl [provider] <url> — atur URL untuk endpoint yang kompatibel.
  • .addai <id> <nama> <baseUrl> <model> [apiKey] — tambahkan provider kustom.
  • .delai <id> — hapus provider kustom.

Contoh format persis dapat dilihat dengan mengetik perintah tanpa argumen. Jangan mengirim API key ke chat grup.

Catatan penting

  • Fitur pengingat sholat otomatis saat ini dijadwalkan untuk wilayah Cilacap.
  • Stiker animasi dari video/GIF memiliki batas durasi 10 detik dan memerlukan FFmpeg.
  • Bot bergantung pada koneksi internet, provider AI, serta layanan eksternal yang digunakan masing-masing fitur.
  • Gunakan bot sesuai aturan WhatsApp dan layanan yang terhubung. Penggunaan yang berlebihan dapat menyebabkan pembatasan akun.
